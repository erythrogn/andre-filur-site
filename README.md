# Andre Filúr — Site Institucional

Site institucional do artista visual brasileiro Andre Filúr, desenvolvido com Next.js 14, TypeScript e Tailwind CSS.

## Sobre o Projeto

Site institucional à altura do trabalho artístico de Andre Filúr — um portfólio visual que funciona como cartão de visita para galerias, colecionadores, curadores e imprensa.

### Características

- Design minimalista e contemplativo
- Paleta de cores terrosa e orgânica
- Bilíngue (Português e Inglês)
- 100% Responsivo (Mobile, Tablet, Desktop)
- Performance otimizada
- SEO-friendly

## Tecnologias Utilizadas

- **Next.js 14** - Framework React com App Router
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Estilização utilitária
- **Google Fonts** - Cormorant Garamond + DM Mono
